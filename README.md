# Análise de Vendas do Tesouro Direto

Este projeto analisa dados de vendas do Tesouro Direto, utilizando Python e Pandas.

## Objetivo

Analisar o histórico de vendas do Tesouro Direto para identificar quais tipos de títulos concentram maior volume financeiro e maior quantidade negociada, avaliar a evolução das vendas ao longo do tempo e verificar possíveis padrões de sazonalidade.

## Perguntas analisadas

- Como são os dados?
- Qual tipo de título mais vende em valor e em quantidade?
- Como as vendas evoluem por mês e por ano?
- Existe sazonalidade?
- Qual o valor médio por operação e como ele varia entre os títulos?

## Ferramentas utilizadas

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- VS Code

## Principais conclusões

O Tesouro Selic apresentou o maior volume financeiro vendido no período analisado. Já em quantidade vendida, o Tesouro Reserva foi o título com maior destaque. Também foram observados crescimento das vendas ao longo dos anos, variações mensais e indícios de sazonalidade.
